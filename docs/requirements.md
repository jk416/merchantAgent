# 智店云 ShopMind 一期需求文档

## 1. 角色定义
- **平台运营**：SaaS 平台方，负责审核商家入驻、套餐定义（一期简化为超级管理员账号）。
- **商家管理员**：租户的老板，注册店铺、配置员工、上架商品、管理订单与库存、配置 AI 客服。
- **商家员工**：客服、运营等，按 RBAC 权限进行后台操作。
- **买家**：在店铺浏览、下单、咨询 AI 客服（前期通过 buyer-mock 模拟，后期配最简 H5）。
- **AI 客服 Agent**：代表特定店铺，基于店铺知识库与工具调用回答问题、查单、办退款。

## 2. 一期核心用例
- **租户 / 商家模块**：店铺注册（并发防重）、登录认证（Sa-Token）、多租户数据逻辑隔离。
- **商品模块**：SPU / SKU 分类与模型、批量导入（多线程/CompletableFuture）、AI 辅助文案生成。
- **库存模块**：设置库存、防超卖扣减（无锁 -> SETNX/Lua -> Redisson -> 乐观锁 -> Redis 预扣）。
- **订单模块**：下单、跨服务调用、超时未支付自动关单（延迟消息）、秒杀高并发削峰。
- **AI 客服 Agent**：SSE 流式输出、Redis 会话记忆、RAG 知识库问答、Function Calling 工具调用（查订单/退款）。
- **SaaS 治理**：租户套餐、Token 额度计数、RPM/TPM 双重限流与熔断降级。

## 3. 明确不做（边界控制）
- 暂不对接真实外部物流（使用 Mock 物流数据）。
- 暂不发送真实短信（验证码在日志中打印 Mock）。
- 复杂营销活动只保留优惠券最简版本。
- 资金结算走支付宝沙箱环境。

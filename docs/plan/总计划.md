## 二、 每日冲刺详细路线

### 阶段二：企业级 RAG 知识库与检索重排工程（V6）

| 天数 | 主题 | 核心内容 | 产出 / 实验 |
| :--- | :--- | :--- | :--- |
| **Day 21** | **多格式文档解析与高级分块** | Markdown / PDF 解析；对比固定长度分块 vs 语义段落分块 vs 递归层级分块对检索召回的影响 | 知识库解析切分组件 |
| **Day 22** | **向量数据库实战与 Embedding 接入** | Docker 部署 PgVector / Milvus；Spring AI 接入 Embedding 模型；多租户元数据（Metadata Filter）隔离入库 | 向量化存储与租户隔离 |
| **Day 23** | **混合检索（Hybrid Search）** | **痛点攻坚**：为什么纯语义搜不出商品货号/规格？实现 Dense 向量检索 + Sparse BM25 关键词双路召回，倒数排名融合（RRF 算法） | 混合检索组件 |
| **Day 24** | **重排器（Re-ranker）与可溯源引用** | 二阶段检索：初检 Top 20 ➔ Cross-Encoder / BGE-Reranker 精排 Top 3；客服回答自动附带可点击溯源角标 `[1][2]` | 检索精排 + 引用溯源 |
| **Day 25** | **RAG 量化评测（AI Eval）** | 引入 Ragas 评测框架：量化评测 Faithfulness（忠实度/防幻觉）、Answer Relevance（相关度）；生成 RAG 调优对比报告 | AI Eval 评测报告 |
